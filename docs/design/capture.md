# Capture

送信済みドキュメントの JSON 受領記録と SQLite の調整状態を `capture-state/` に保つ。現在のフォルダーと旧 Codex ホストの `remnifold/`、`kagayoi-memory/`、`cloudflare-memory/` を和集合で読み、書き込みは現在の場所だけに行う。決定的キーと未確認記録の再試行で重複を防ぐ。本文の管理情報はメタデータに置き、旧 v2 の完全一致する生成ヘッダーだけを取得時に除く。既存の本文、受領記録、公式メモリは変えない。

## トランスクリプトとターン

Codex のインポートは rollout だけを読む。`session_meta` のない入力は、フックの `sessionId` を持つ Claude のメイン user/assistant 行があるときだけ受け入れる。行は `type` で分類し、要求コピー、添付、サイドチェーン、メタ、圧縮要約、ツール、他セッションを除く。人間の依頼は `origin.kind: human`、古い行では既知の自動ラッパー以外とする。同じ `message.id` のテキストを結び、最後の回答を使う。通知は固定ラベルの継続ターンにし、保存済みターンのハッシュを変えない。v2 キーと `sm_source: "claude-code"` を使い、最新の `custom-title` をタイトルにする。

想起のリセットは Codex と Claude の圧縮行も認識する。継続ターンの説明は返信と直前の依頼から作り、読み取り時にも旧ラベルを補う。保存しない `lowInformation` を手動検索時に導き、待機だけの短文を同程度の一致の後ろに置く。自動想起には使わず、結果のある返信を落とさないよう見逃しを許す。

## セッションイベント

Claude の `Stop` はターンの後に、圧縮の AI 要約、途中の人間のメッセージ、`AskUserQuestion` の構造化された回答を別記録で送る。途中メッセージからサイドチェーン、コマンド、60秒以内に人間の依頼と重複するものを除く。ID は `claude-event-v1:{sessionId}:{kind}:{key}`（255文字以内）、key は uuid か `tool_use_id`。`type: session-event` と `eventKind` を持ち、ターン、パート、capture キーは持たないので、整理・リビジョン選択・最近タスクには入らない。収まらない記録は次の `Stop` に送る。圧縮フックは足さない。

圧縮要約は承認でない手がかりと明記し、`recallable: false` とする。補強、統合、自動想起はせず、手動検索は許す。途中メッセージと回答はターンと同じ人間の発言として扱う。圧縮直後は以前の `Stop` の分しか検索できない。

要約と回答では妥当な電話番号とメール（`git@host` を除く）を伏せ、個人情報の質問への自由記述を置き換える。区切りのない番号や表現のすり抜け、選択肢、他の自由記述は残り、要約が発言を言い換えうる。途中メッセージには連絡先の伏せ字がない。忘却したイベントは受領記録喪失後の再送で戻りうる。索引には `kind=` を足す。

## 伏せ字と失敗

設定キーと引用付きシークレット代入値を伏せる。履歴読み取りの同時数と最終件数を制限する。新しい出力の UTF-16 切断はサロゲートを守るが、V2 のハッシュは元の長さと固定パートを使う。失敗は固定の段階・原因・対処だけを示し、例外、パス、設定、応答を出さない。`repair-required` は再試行だけでは直らない。

## 行とイベントの判定

Claude 行は `message.role` でなく `type` を使い、`api-request-blob` と `queue-operation` を除く。`compact_boundary` と `isCompactSummary` を圧縮とみなす。途中発言は `queued_command` 添付の `commandMode: "prompt"` と `origin.kind: "human"`、回答は `toolUseResult` だけを使い、選択肢は含めない。本文ハッシュは伏せ字済みソースから求め、伏せ字規則を変えてもイベント ID は変わらない。
