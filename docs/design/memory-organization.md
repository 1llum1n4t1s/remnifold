# Memory organization

利用者が呼ぶ `skills/organize-memory/` が実行し、結論は Codex が作る。Worker は整理のためにモデルを呼ばず、スケジュールも登録しない。埋め込み・ベクトルの回復と、別のプロジェクト統合は Worker が続ける。コマンドと入力の契約は [commands.md](commands.md)、埋め込みと可視性は [vector-reconciliation.md](vector-reconciliation.md)。

## キューと準備

移行 0009 はバッチ、ソースのリビジョン、網羅範囲、非公開の継続をメタデータ外に持つ。リースは 30 分、対象 20 件、本文 48,000 UTF-16 単位、候補要約 8 件、1 チャンク 8,000 単位まで。JSON も 1 MiB 未満に収める。4 レーン（マルチパート、継続、期限の来た先送り、未処理）を巡回し、安定カーソルと 512 行の探索窓で飢餓を防ぐ。公平性は窓の内側に限る。

範囲指定は DB 時刻の `created_at` を使い、グローバルと公平性のカーソルを動かさない。`range.cursor` から 512 行窓を最大 8 つ調べ、空窓だけを進める。空でも `exhausted:false` なら上限で、次回続ける。移行 0013 はこの走査の索引。対象 ID 指定との併用は拒む。自動の先送りは 1 時間後で、移行 0012 は旧期限を調整した。

## 要約と網羅

commit は最大 8 要約・計 24,000 単位と、各ソースの網羅表明を受ける。要約は物理コンテナ、scope、プロジェクト ID と表示名、想起クラスの厳密なパーティションを越えない。共通と証明できるパスだけ継承し、手動専用と opt-out を保つ。登録された生成版のマーカーだけが権威を持つ。整理索引の `recallable: true` は短い結論でも尊重する。

完全な網羅には最後のチャンクと全結論・理由・不確かさが要る。部分は非公開メモ、先送りは再試行だけを保存し、元記録は見えるままにする。意味的な完全性は Codex の表明でサーバーは証明しない。マルチパートは全パートの読了まで非公開 `groupProgress` に留め、確定時に要約と全体の網羅を原子的に公開する。時系列はセッション内で信頼できる場合だけ使い、後の保存を新しい決定とみなさない。

同じ capture 識別に複数 ID があれば先送りする。例外はサーバーが本文の SHA-256 と独立キーを検証した単一パート v2 だけで、最新版の証明ではない。検証できない本文は `capture-hash-unverifiable`。移行 0010 と現行の衝突ビューが commit 時にも証明する。クールダウンだけでは衝突を解消しない。安全な整数でないターン/パートも先送りする。

## 公開と無効化

公開は 1 つの D1 バッチでリース、以前の要約、全ソースを検証する。同一再試行は保存済み応答、異なる内容は conflict。スナップショットは ID と位置だけを保ち、完了後に捨てる。要約の直接更新は禁止する。

元記録は消さず、直接取得と一覧には残す。必要な要約の全てが有効な間だけ通常検索と話題想起から隠す。ソースの編集、再補強、忘却、復元、物理削除は SQLite トリガーで要約を無効にし、失敗なら変更ごと戻す。複数要約のどれか一つの失敗でも元を再表示する。

旧チェックポイントは全体を一記録として扱い、正確なメンバーシップを無効化の来歴に加えるが、内容は展開しない。完全に網羅されるまで見えるままにする。置き換えは依存要約を保守的に無効にする。統合は隠れた原本を読み、生成要約は除く。有限の実行はアーカイブ全体の完了を意味しない。

## キューの細部

- 継続窓は 64 ID。窓内で期限の来た記録とグループは再試行時刻、ID の順に並べ、非アクティブなグループが進捗と新規の優先度を決める。無効グループは網羅回復のため未処理の優先度とソースの期限を使う。未処理の時期は `created_at`（決定日ではない）。
- 再試行時刻が等しい間はマルチパートを優先するが、後方の候補が前の通常記録を押しのけない。空のレーンは次へ譲る。
- 範囲走査は `(created_at,id)` 順。候補のある窓ではカーソルを進めず、完了・先送り・リース中の行が外れていく。
- 移行 0012（`0012_organization_retry_fairness.sql`）は、残る旧先送りとグループの期限を 23 時間早め、元の時刻の 1 時間後とする。他の状態は変えない。
- リビジョンが変わると非公開進捗を捨てる。欠落・変更・忘却・パーティション衝突のメンバーはグループを無効にするか先送りする。
- 整理索引は `sourceKind: "organization"` のバージョン1だけ短い `recallable: true` を尊重する。句読点だけの要約は公開できない。
