# Dependency maintenance

- Rust のマニフェストとルートの `Cargo.lock` を一緒に更新し、ロック付きのチェックを実行する。ネイティブクレートが宣言する最低限の Rust は、開発・CI のツールチェーンとは別に保つ（[Validation](validation.md) を参照）。
- ネイティブツールのバージョン、ダウンロード URL、SRI 値は `dev/` に固定されている。そのマニフェストと完全性の期待値を一緒に更新する。アーカイブのトラバーサル、リンクされたパス、キャッシュ済みツールの改ざん、ダイジェストの各チェックを有効に保つ。完全性チェックを弱めたり、フォールバックとして JavaScript パッケージマネージャーを呼び出したりしない。
- `.github/dependabot.yml` が、Cargo ワークスペースの依存関係と SHA 固定の GitHub Actions を毎週対象にし、マイナー／パッチの更新をメジャーとは別にする状態を保つ。
