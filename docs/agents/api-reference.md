# API reference contracts

## リモート MCP と OAuth

REST/クライアント互換、追加型の移行、トランスポート検証、オリジンと同意の検査、資格情報の伏せ字、再試行安全な保存、並行する code/refresh の一度だけの交換、失効、オーナーキー更新、登録上限、OAuth 移行なしの失敗を検証する。プロビジョニングの認証検証は公開 MCP ツールと一致させる。

認可ページは次を保つ。

- 同一オリジンの同意リファラーと `form-action 'self'`
- スクリプトなしの HTTP 200 完了と、一致する meta-refresh/フォールバック先
- `no-store`/`no-referrer` と同意クッキーの消去
- 登録済み識別と `state` を保つエスケープ済みコールバック
- null/外部オリジン、不安全なリダイレクト名、デコード後の重複パラメーターと過大フィールドの拒否
